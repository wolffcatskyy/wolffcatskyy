# wolffcatskyy

CrowdSec + UniFi security tooling. Blocklist imports, firewall bouncers, and log parsers that run on hardware you already own.

## CrowdSec

- **[crowdsec-blocklist-import](https://github.com/wolffcatskyy/crowdsec-blocklist-import)** - 10-20x more blocks for your CrowdSec bouncers: 120k+ IPs from 30+ free threat feeds. Docker image and Homebrew formula.
- **[awesome-crowdsec](https://github.com/wolffcatskyy/awesome-crowdsec)** - Curated list of CrowdSec resources and integrations

## UniFi

- **[crowdsec-unifi-bouncer](https://github.com/wolffcatskyy/crowdsec-unifi-bouncer)** - Install and persist the official CrowdSec firewall bouncer on UniFi OS devices (UDM, UDM SE, UDR), with automatic recovery from firmware updates
- **[crowdsec-unifi-parser](https://github.com/wolffcatskyy/crowdsec-unifi-parser)** - CrowdSec parsers and iptables LOG rules for UniFi firewall logs
- **[crowdsec-unifi-suite](https://github.com/wolffcatskyy/crowdsec-unifi-suite)** - One-command installer for the CrowdSec + UniFi stack (bouncer + parser + blocklist-import)
- **[awesome-unifi](https://github.com/wolffcatskyy/awesome-unifi)** - Curated list of UniFi and Ubiquiti networking tools, libraries, and resources

## Legacy Mac (maintenance mode)

Still maintained - bugs get fixed - but not the focus:

- **[smcFanControl Community Edition](https://github.com/wolffcatskyy/smcFanControl)** - Fan control for Intel Macs, with boot-time fan control and a modern UI
- **[linux-mac](https://github.com/wolffcatskyy/linux-mac)** - Custom Linux kernels built for Apple Mac hardware
- **[cachyos-macpro-iso](https://github.com/wolffcatskyy/cachyos-macpro-iso)** - CachyOS ISO for the Mac Pro 6,1 (Late 2013) with GPU firmware and full hardware support
- **[chrome-macpro-gpu-patch](https://github.com/wolffcatskyy/chrome-macpro-gpu-patch)** - Restore Chrome hardware acceleration on legacy Mac GPUs via OCLP
