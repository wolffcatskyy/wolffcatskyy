# wolffcatskyy

Security and homelab tools developer. Building open source infrastructure for self-hosters — with a focus on **CrowdSec** and **UniFi** ecosystems, plus tools that keep older Intel Macs useful.

## UniFi & Network Security

Tools for securing and extending UniFi/Ubiquiti networks:

- **[crowdsec-unifi-bouncer](https://github.com/wolffcatskyy/crowdsec-unifi-bouncer)** — Install and persist the CrowdSec firewall bouncer on UniFi OS devices (UDM, UDM SE, UDR) with automatic recovery from firmware updates
- **[awesome-unifi](https://github.com/wolffcatskyy/awesome-unifi)** — A curated list of awesome UniFi and Ubiquiti networking tools, libraries, and resources
- **[crowdsec-unifi-parser](https://github.com/wolffcatskyy/crowdsec-unifi-parser)** — CrowdSec parsers for UniFi firewall logs

## Legacy Mac & Linux-on-Mac

Keeping Intel Macs running well, on macOS or Linux:

- **[smcFanControl Community Edition](https://github.com/wolffcatskyy/smcFanControl)** - Fan control for Intel Macs, with boot-time fan control and a modern UI
- **[linux-mac](https://github.com/wolffcatskyy/linux-mac)** - Custom Linux kernels built for Apple Mac hardware
- **[cachyos-macpro-iso](https://github.com/wolffcatskyy/cachyos-macpro-iso)** - CachyOS ISO for the Mac Pro 6,1 (Late 2013) with GPU firmware and full hardware support
- **[chrome-macpro-gpu-patch](https://github.com/wolffcatskyy/chrome-macpro-gpu-patch)** - Restore Chrome hardware acceleration on legacy Mac GPUs running Sequoia and Sonoma via OCLP
